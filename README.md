🎬 Movies Project

This is a Movie Finder project created as a learning project to practice and improve my React, API integration, state management, and local storage skills.

📌 About the Project

The application gets movie data from an external API and displays the available movies to the user. Users can also search for their favorite movies and get the results directly from the API.

The project uses two-way data binding for the search functionality, allowing the input field and application state to stay synchronized.

✨ Features

- 🎥 Fetch movies from an API
- 🔍 Search for favorite movies
- ⚛️ Built with React
- 🔄 Two-way data binding for search
- ❤️ Save favorite movies to a watchlist
- 💾 Store saved movies in Local Storage
- 📋 Display saved movies in the watchlist section
- 🗑️ Manually remove movies from the watchlist
- 🔒 Saved movies remain available after refreshing or reopening the application
- 🧹 Movies can be removed manually or by clearing Local Storage

🛠️ Technologies Used

- React.js
- JavaScript
- API Integration
- Local Storage
- HTML
- CSS

🎯 Learning Objectives

Through this project, I practiced working with APIs, handling asynchronous data, managing React state, passing data between components, implementing search functionality, and storing persistent data using browser Local Storage.

This project is part of my journey to improve my React and web development skills.
